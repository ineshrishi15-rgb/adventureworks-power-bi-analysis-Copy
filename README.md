# AdventureWorks Business Intelligence Analysis | Power BI

## Project Overview
This project uses Microsoft Power BI to explore AdventureWorks business data and present interactive insights into product performance, category-level trends, returns, and customer behaviour.

## Report Pages
- **Category Analysis:** Explore category-level sales, quantities, orders, and returns.
- **Product Analysis:** Examine product performance and trends.
- **Customer Analysis:** Explore customer-level metrics and purchasing patterns.
- **Category Order Distribution Tooltip:** Provide additional category-level context through a report tooltip.

## Tools Used
- Microsoft Power BI Desktop
- Power Query
- DAX
- Data Visualisation and Reporting

## Key Features
- KPI cards for business performance metrics
- Interactive filters and slicers
- Category and product comparisons
- Customer analysis
- Tooltip-based reporting

## Business Objective
The goal is to organise business data into an interactive report that helps users explore performance, identify patterns, and support data-informed decisions.

## Files
- `AdventureWorks Analysis 7th Jun(2).pbix` — Power BI report file

## How to Use
1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Interact with the report pages and available slicers.

## Notes
This is a portfolio project based on an existing Power BI report. Findings and business recommendations should be documented after validating the underlying data, measures, and report results.
